# 三人惯蛋

一个简单的三人纸牌游戏（单副牌，54张），可以在家里连接同一个WiFi时一起玩，不需要联网、不需要部署到云端。

## 怎么玩（局域网 / 同一WiFi）

1. 找一台电脑（Windows / Mac 都行）作为"主机"，安装好 [Node.js](https://nodejs.org/)（建议 v18 及以上）。
2. 在这台电脑上，进入本项目目录，安装依赖并启动服务器：

   ```bash
   npm install
   npm start
   ```

3. 启动成功后，终端会打印出类似下面的地址：

   ```
   ======================================
     家人在同一WiFi下，用手机/电脑浏览器打开:
     http://192.168.1.5:3000
   ======================================
   ```

4. 让家里的三个人（包括主机自己）确保手机/电脑都连接**同一个WiFi**，然后在浏览器里打开上面打印出来的地址（比如 `http://192.168.1.5:3000`）。
5. 每个人输入自己的名字进入大厅：
   - 第一个人点击"创建房间"，把生成的房间号告诉另外两个人；
   - 另外两个人点击"加入房间"，输入房间号加入。
6. 三人到齐后游戏自动开始，轮流出牌，规则见下方。

> 提示：如果打不开，检查一下手机和电脑是不是连了同一个WiFi（不能一个用WiFi一个用手机流量），以及电脑上的防火墙有没有拦截 3000 端口。

## 玩法规则（简化版）

- 一副牌（不含大小王的52张 + 大王小王）平均分给三人，每人18张。
- 从创建房间的玩家开始，按顺序轮流出牌，可以出的牌型：
  - 单张、对子、三张
  - 三带一、三带一对
  - 顺子（5张及以上，3~A 之间的连续单张，不能带2和王）
  - 炸弹（四张相同点数），炸弹可以炸任何非炸弹的牌
  - 火箭（大王+小王），最大，可以炸任何牌
- 出的牌必须和上家同类型、张数相同且点数更大，或者用炸弹/火箭压过去；轮到自己也可以选择"不出"。
- 谁先出完手里的牌，谁获胜。
- 点击"理牌"可以把手上的牌按点数重新排序。

## 局域网之外（可选）

如果想让不在同一WiFi下的人也能玩（比如异地家人），可以参考 `deploy.sh` 脚本部署到云端（Render + Cloudflare Pages 等），但那不是必须的——同一个屋檐下用WiFi玩，直接用上面的方法就够了。
